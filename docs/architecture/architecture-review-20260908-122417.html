Problem

  • Name drift becomes a test, not a silent drop
  • Deletes ~60 duplicated lines
  • On-disk layout stops leaking across the seam
  • Testable on a 20-row fixture, not 250MB

binary_experiment.py:60-77. Every caught exception writes a row labelled with the failing method but carrying the previous method's estimate. Introduced by commit 125ae9b (“add try except for experiments”). Behind an estimator seam the failure has one place to be handled, so this shape is unreachable.

Problem
Simulation, per-method calling convention, failure handling, metric and row shaping share one body; adding a method means editing an if-chain over registry key strings.
Solution
One estimator interface with an adapter per calling convention; the registry maps name to adapter. The sweep takes a spec value instead of from variables import *.
  • Leverage: one interface, 4 calling conventions
  • Locality: CC and QuaDapt special cases concentrate
  • Stale-prediction bug becomes unreachable
  • Test one estimator on a fixed score pair
  • Smoke sweep runs in seconds, not hours
  • Grid stops being module globals
Related: variables.py:69-70 keeps a smaller grid commented out. That is the sweep asking for a parameter it does not have. from variables import * also supplies np, pd and get_prev_from_labels ambiently — the sweep's real interface is wider than it looks.
